Solver

MATLAB, in the controlled 1-parameter case directory. The solver builds the SBP differentiation operator, the burst kernel, and the projected right-hand side, and integrates with explicit fourth-order Runge–Kutta under the CFL restriction set by the spectrum of \(\mathbf{V}\).

Core MATLAB routines.
ScriptRole
PIDE_1P_controlled.mClosed-loop ensemble solve, one uncertain parameter.
make_tracking_controller.mBuilds the PDF-shape tracking controller.
PIDE_1P_deploy.mDeploys a controller on the true uncertain ensemble; supports feedback_mode = 'ensemble' | 'nominal'.
PIDE_1P_robustness_validation.mRuns the whole PCE-vs-nominal comparison and the uncertainty sweep.
PIDE_2P_controlled.mTwo-parameter (mean-field) case.
PIDE_2D_controlled.m, PIDE_2D_2param_controlled.mJoint two-dimensional cases.
validate_PIDE_vs_SELANSI.mCross-check against the SELANSI reference toolbox.

To reproduce the headline robustness comparison:

PIDE_1P_robustness_validation   % set do_sweep = false to skip the uncertainty sweep

The script first cross-checks PIDE_1P_deploy(..., 'ensemble') against PIDE_1P_controlled — these should agree to about \(10^{-12}\) — then runs the comparison, prints the metrics table, and plots.

Verified Python reference

A NumPy port of the same scheme exists as an independent reference, in the robustness_study directory. It is what produced the numbers on the control page. 

python step1_verify.py   # PCE vs deterministic solve, and vs Monte Carlo
python step3_final.py    # headline +/-20% comparison, with PCE-order convergence guard
python step4_sweep.py    # robustness vs uncertainty magnitude
python make_figure.py    # robustness_summary.png

python step6_modeA.py        # autoregulation actuator (Mode A)
python step6b_modeA_sweep.py # Mode A uncertainty sweep
python step7_jensen.py       # Jensen-gap check

Verification performed

  • The NumPy port matches the deterministic solve at \(\gamma_x = c_1\) to about \(7\times10^{-16}\), and matches brute-force Monte Carlo mean and variance to under 0.5% and about 3% respectively (sampling noise).
  • PCE-order guard: orders \(p = 3, 5, 7\) give identical metrics at ±20%, confirming the expansion is converged there. The wider-spread sweep uses \(p = 5\).
  • PIDE_1P_deploy reuses the same SBP, kernel and right-hand-side construction as the main solver, and is cross-checked against it on the first run.

Known caveats

  • The MATLAB robustness scripts were written to mirror the verified Python but could not be executed in the environment where they were written (no MATLAB or Octave available there). The built-in cross-check exists so that fidelity can be confirmed on the first run.
  • Absolute metric values depend on the target \(p^*\), the controller gains, and the grid. The relative PCE-vs-nominal comparison is the result, not the absolute numbers.
  • The default configuration is Mode B (inducer_only = true), a clean monotonic actuator. Setting params.inducer_only = false repeats the study under the autoregulation model.

Reference implementation used for validation

Monte Carlo reference solutions were generated with SELANSI, a MATLAB toolbox for fast evaluation of PIDEs (Pájaro et al.). For the one-dimensional self-regulated case an analytical steady-state solution is also available and was used as an independent benchmark.
